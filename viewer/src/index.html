swarm-git viewer

a git forge with no server — repository and viewer both live on Swarm

This page reads a Git repository stored on Ethereum Swarm and renders it here, in your browser. It fetches the manifest and packfiles from a Swarm gateway and reconstructs the repository client-side. There is no backend: nothing runs anywhere except this tab.

A feed manifest reference works through any public gateway. The <owner>/<repo> form needs a local Bee node, because gateways do not serve the /feeds endpoint — pass one with ?gateway=http://localhost:1633.
